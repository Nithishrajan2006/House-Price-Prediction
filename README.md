# House Price Prediction

This project predicts house prices using Machine Learning techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
The dataset contains house-related features such as:
- Bedrooms
- Bathrooms
- Square Footage
- Floors
- Waterfront
- Condition

## Project Objective
To build a machine learning model that predicts house prices based on property features and historical data.
